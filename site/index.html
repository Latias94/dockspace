A renderer-neutral Rust library

Docking layouts
for your editor.

Tabs, nested splits, floating groups, and motion. Dockspace manages the layout and interactions. Your application owns the pane content and chooses how to draw it.

Try the egui demo ↗ Read the integration guide →

Pre-release Use from source. The API may change.

01 / Layout

A place for every pane.

Compose tabs and nested splits. Reorder, merge, resize, or float a group within the same surface.

02 / Ownership

Your content stays yours.

Keep documents, editor state, drawing, and close decisions in your application. The core owns docking state.

03 / Motion

Make changes easy to follow.

Interruptible layout and drop-preview motion, with configurable timing, curves, and reduced-motion support.
